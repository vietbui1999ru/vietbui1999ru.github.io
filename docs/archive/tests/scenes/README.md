# Archived scene tests

These tests cover the legacy Three.js/r3f scene playground under `src/scenes/`,
including the magnetic and singularity experiments. They are intentionally outside
Vitest's `tests/**/*.test.*` discovery path because the current portfolio version
ships the paper UI and Ink Ambient effect, not the scene playground.

The source files remain available for historical reference and may be deleted in a
separate cleanup when the `/sim/*` routes are removed.
